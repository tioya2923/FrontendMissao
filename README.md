# Projecto Missão - Frontend

Frontend web application para o Projecto Missão em Huambo, Angola.

## 📖 Sobre o Projeto

Este é o site oficial do Projecto Missão, uma iniciativa dedicada a servir a comunidade de Huambo através de programas espirituais, educacionais e sociais. O site fornece informações sobre:

- **Serviços e Programas**: Cultos, educação, ação social
- **Sobre Nós**: Missão, visão e valores do projeto
- **Contacto**: Informações para entrar em contacto e visitar

## 🛠️ Tecnologias

- **React 19**: Biblioteca JavaScript para construção de interfaces
- **Vite**: Build tool moderna e rápida
- **React Router**: Navegação entre páginas
- **CSS3**: Estilização responsiva e moderna

## 🚀 Como Executar

### Pré-requisitos

- Node.js (versão 16 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/tioya2923/FrontendMissao.git
cd FrontendMissao
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Acesse no navegador:
```
http://localhost:5173
```

## 📦 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a versão de produção
- `npm run preview` - Visualiza a versão de produção localmente
- `npm run lint` - Executa o linter para verificar o código
